OPTIONAL one external/on-site link per string: {% include link-names.html text=e.text link=e.link link_text=e.link_text %} `link_text` is words copied from `text`; they become the link. Naming the destination in the link text reads better than "read more" and satisfies WCAG 2.4.4 (link purpose). With no usable `link_text` we append a short "Details ↗" link carrying an aria-label built from the sentence. ORDER MATTERS. The phrase is swapped for a sentinel BEFORE names are linked, then restored as an afterwards. That is what keeps a phrase which contains (or equals) a member name from producing a nested — the sentinel hides it from the name pass, so such a phrase links out and is simply not name-linked. Doing it the other way round nests anchors, which is invalid HTML and makes the inner link unreachable by keyboard.
